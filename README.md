# Portfolio Cybersecurity

Data kamu ada di file-file ini:

- profile.json: nama, bio, sosial media, skill (dengan level 0-100), dan jumlah ctf
- projects.json: daftar project. status "done" atau "wip"
- writeups.json: daftar write-up
- file .md: isi write-up
- profile.jpg: foto profil

Desain ada di style.css (bagian :root paling atas untuk warna).
